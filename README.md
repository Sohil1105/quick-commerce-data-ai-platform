# Zepto Data & AI Platform

Unified capstone repository containing three internally-linked AI/ML modules:
- `/data_pipeline` — Web scraping, cleaning, currency conversion, and normalized SQLite + Pandas analytics pipeline.
- `/analytics` — Titanic exploratory data analysis, statistical profiling, classification, and regression modeling pipeline.
- `/support_assistant` — Grounded RAG support service powered by ChromaDB, SentenceTransformers, LangGraph, Pydantic, FastAPI, and Docker.
